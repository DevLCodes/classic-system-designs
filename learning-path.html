    How to use it

    • Read the blocks in a stage before its walkthroughs. Each walkthrough reuses the blocks listed above it, so the deep dives land better.
    • Count a page as done when you can explain its main trade-off without looking and you've tried its lab. The study hub has flashcards and a quiz for every page to check yourself.
    • Progress is kept in this browser's local storage, so it survives a reload but not a private window or a different device. If storage is blocked, the ticks still work until you leave the page.
    • For an interview, stages 1 to 3 cover most questions. Stage 4 is for senior loops and for anyone curious how databases agree on anything.
